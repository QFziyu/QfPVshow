# V1 验证说明

本地检查环境：Windows、Node.js 24、Python 3、@napi-rs/canvas 0.1.100。

| 检查组 | 数量 | 范围 |
| --- | ---: | --- |
| 模型与文件 | 19 | 关键帧、锁定、轨迹、跟随、格式迁移、ZIP、字幕时间 |
| 界面事件模拟 | 40 | 选择、拖动、字幕编辑、留白、标签切换、键盘导航、作者窗口、导出入口 |
| 合成与导出 | 23 | 实际 Canvas 像素、逐句合成、PNG、项目包、AE 结构与宿主接口模拟 |
| 整合检查 | 14 | 27 套配色与 860 项效果、动态区域与媒体保留、后期避让、AE 动态蒙版 |
| **总计** | **96** | 自动检查 |

歌曲分类检查内部包含 6 类 × 20 个种子 × 两种统一感设置，共 240 组编排。构建后另检查内嵌脚本语法及作者 / 名称信息。

当前可用浏览器阻止本地文件访问，未进行真实浏览器截图和布局实测；界面测试使用 DOM 夹具与实际 Canvas，不冒充浏览器端到端测试。窄屏样式实现了 1200 / 900 / 560 像素断点，但仍需在真实设备上检查。

MP4 使用编码器模拟。浏览器视频解码、硬件 MP4 编码、真实 After Effects 宿主未实测；GitHub Actions 配置已提供，但未在远程 GitHub 上运行。

执行 `npm run build`、`npm test` 可重现本地检查并生成 `tests/verification.json`。`npm run release` 会重新构建、检查后打包，避免将旧的测试结果当成本次检查。
