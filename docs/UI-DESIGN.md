# V1 界面设计约定

作者：QFziyu。方向是原 JIZURA 的深色、紧凑创作工具感，改用温暖中性色，不复制其高饱和青色和金黄强调。

## 颜色

| 用途 | 色值 |
| --- | --- |
| 应用背景 | `#171614` |
| 面板 | `#201e1b` |
| 控件表面 | `#292622` |
| 主文字 | `#ede6dd` |
| 次文字 | `#b0a69a` |
| 主要交互 / 铜色 | `#c7a583` |
| 边界 | `#39342e` |

无渐变主按钮、荧光绿或青蓝发光边框。模板成片自身的色彩属于创作素材，不被 UI 主题统一改色。

## 信息层级

页头是小型 QF 标识、项目名称与文件操作。作者小字仅作署名；完整来源集中于关于窗口和 README-SOURCES。

左栏依次是素材、风格、构图；右栏依次是元素、运动、导出；中间保留连续的预览、传输控制和时间轴。复杂模板与打轴选项渐进展开。页头导出快捷入口避免滚动查找。选择字幕或留白的专用按钮会打开对应属性页。

控件标注通常 11px，输入与主控件 12px，分组标题 12–16px；提升旧版 9px 辅助文字的可读性。状态不只依靠颜色，标签同时使用底线、文字与 aria-selected。支持键盘焦点、方向键和 Home / End。

在较窄屏幕，预览位于上方，两侧面板移到下方；手机宽度为单列。具体实现见 src/style.css。真实浏览器验证边界见 VALIDATION.md。
