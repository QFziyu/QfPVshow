# Qf-PV show V1 使用指南

作者：QFziyu。先用 Chrome / Edge 打开根目录 `index.html`。

## 1. 素材与歌词

左侧“素材”集中放置音乐、背景、人物 / 前景、歌词及打轴工具。歌词每行一句，`/` 可拆分镜头；也可导入 LRC / SRT。导入人物 PNG 时放在“人物 / 前景”，以便动态留白区域内继续显示人物。

“逐句独立编辑字幕”让每句拥有独立外部运动；原模板内部字效仍然保留。点击歌词行可跳到对应句并选中控制图层。字幕支持本句改写、失联重关联和保留轨迹。

“听音打轴”中先准备歌词，然后播放，逐句按 T 记录起点；可修正时间、吸附节拍、设置整体偏移，再应用到字幕。它是手动辅助打轴，不是自动语音识别。

## 2. 风格编排

左侧“风格”中选择：

- **歌曲风格：** 慢歌抒情、极简叙事、流行轻快、摇滚燃曲、电子舞曲、电影感，或自由搭配。
- **视觉配色：** 27 套原引擎配色。
- **背景与生成方案：** JIZURA 完整风格，或五套由独立几何元素组成的背景。

点击“生成当前风格”编排。重新生成保留手工改过、锁定、被跟随的独立元素。“只换背景”保留字幕编排，“清理生成背景”只清理未修改的自动背景。

“完整模板库与扩展效果”可以开关扩展、文字 PV、动感文字、和风与恐怖内容。按效果类别与名称搜索后，应用到当前歌词行。手动指定会解除该行编排锁，不删除该句人工运动。歌曲分类会约束随机候选池；自由搭配使用已开启库。

## 3. 构图与动态留白

左侧“构图”设置画幅、帧率和分辨率。启用动态留白，点“选中 / 编辑留白”，右侧会自动显示元素属性。

- 拖动区域内部改变位置，拖角点分别改变宽高，拖上方圆点旋转。
- 右侧可直接填写 X / Y、留白宽度 / 高度、缩放与旋转。
- 画布上方“拖动修改”选“当前帧关键帧”：在不同时间拖动区域，产生动画。首次在后面的帧写键时，系统会补一个起点键。
- “整体移动，保留轨迹”修改整段运动；含锁定点时拒绝整体变换。改用当前帧模式或先解锁。
- “字幕分布”选择左右或上下；“居中”按当前编辑模式修改位置。

区域是一个可旋转矩形，不支持多个区域或自由多边形。字幕、自由文字、图形、追踪框和装饰会避让；底色、图片、视频和人物素材保持可见。手动将字幕移入保护区时，重叠部分会被裁掉。区域太大或靠边会压缩文字可用空间。

辅助框不进入导出，后期效果也不能重新填入保护区。

## 4. 元素、关键帧与运动

右侧“元素”编辑图层名称、内容、颜色、位置、缩放、旋转和显示区间。背景几何、自由素材及字幕句图层都可独立控制。

默认拖动整体平移轨迹。切换“当前帧关键帧”后拖动才写键。画布支持框选、多选、Alt 点选重叠下层元素；双击元素可回到属性面板。

时间轴可框选关键帧、成组拖时间、复制、粘贴、删除及锁定。源关键帧与处理后关键帧分开保存；修改源键会清除过期处理结果。

右侧“运动”集中跟随、单点 / 两点手动追踪、手绘路径、速度曲线、平滑与关键帧压缩。切换标签不会重建项目或删除当前选择。字幕内部字效和外部运动叠加。

标签可以用左右方向键和 Home / End 切换，键盘焦点会跟随。页头“导出作品”直接打开导出页。

## 5. 保存与导出

“保存项目”输出包含媒体和关键帧的 `.pvf`；本地草稿不包含原始素材字节。V1 使用独立草稿，不覆盖旧版；用“打开项目”可载入旧 `.pvf` 或 JIZURA JSON。

- **MP4：** 用于直接播放，实际可用编码能力取决于浏览器和硬件。
- **PNG 序列：** 可去底色及背景媒体，保留几何和人物前景；可在 AE 中还原浏览器画面。
- **WAV：** 单独输出音轨。
- **AE 工程包：** 解压后在 AE 执行 `build.jsx`，生成合成，再另存 AEP。字幕、形状及运动保持可编辑；动态留白输出减去蒙版。
- **项目 JSON：** 不携带媒体字节，重新打开时可能需要关联素材。

AE 原生字幕沿用原始分带位置，与浏览器的动态分带重排有差异；字体、特效和后期也可能不同。需要画面一致时用 PNG 序列与 WAV。
